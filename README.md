# Autonomous Robot Navigation Simulator

Proyek simulasi robot sederhana berbasis Python untuk mempelajari dasar-dasar navigasi otonom, pemrosesan sensor virtual, dan logika pengambilan keputusan.

## Fitur
- Grid Arena 2D: Representasi peta menggunakan matriks Python.
- Virtual Sensor: Sistem pembacaan lingkungan di 4 arah (Atas, Bawah, Kiri, Kanan).
- Decision Making Controller: Logika `if-elif-else` bagi robot untuk menentukan jalur aman dari rintangan (`#`).

## Bahasa & Tools
- Python 3
- Visual Studio Code
- Git & GitHub

## Cara Menjalankan Program
1. Pastikan Python sudah terinstal di komputer.
2. Unduh atau salin (*clone*) repositori ini.
3. Jalankan file melalui terminal:
   ```bash
   python robot_sim.py
